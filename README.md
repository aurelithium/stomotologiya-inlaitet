# Стоматология «Инлайт»

Адаптивный сайт для телефонов, планшетов и компьютеров.

## Технологии
- React 19 + TypeScript
- Vite 7
- Tailwind CSS 4
- vite-plugin-singlefile
- Локальные фотографии из `src/assets/images/`

## Сборка на Windows
1. Установите Node.js 22 LTS: https://nodejs.org/
2. Откройте эту папку в Проводнике.
3. Запустите `СОБРАТЬ_САЙТ.bat`.
4. После завершения сборки готовый автономный файл будет в `dist/index.html`.

Также можно выполнить в терминале из корня проекта:
```bash
npm ci
npm run build
```

## Публикация
В архив уже добавлен `.github/workflows/deploy.yml`: он собирает проект и публикует `dist` через GitHub Pages. В настройках репозитория выберите **Settings → Pages → Source → GitHub Actions**.

Не загружайте `node_modules`. Папка `dist` создаётся при сборке. В проекте установлен относительный `base: "./"` для корректной работы на GitHub Pages.

## Адаптивность
- мобильная версия: компактная навигация, удобные зоны нажатия, поля форм без автоматического увеличения на iPhone, нижняя панель «Позвонить / Записаться»;
- планшеты: адаптированные интервалы и размеры заголовков;
- компьютеры: исходная широкая сетка, крупные секции и навигация;
- учтены safe-area отступы устройств с вырезами и системной панелью жестов.
